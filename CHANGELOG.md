# Changelog

All notable changes to `ima-skills-pro` are documented in this file.

This repository is currently maintained as an enhancement suite based on the official `ima-skills` `1.2` capability baseline.

## [1.2.0-pro] - 2026-03-31

### Added

- Renamed the suite identity to `ima-skills-pro` to distinguish it from the official `ima-skills` package
- Repositioned the repository as a soft-dependency enhancement suite on top of the official package
- Added `OFFICIAL-USAGE.md` as an official usage guide snapshot inside the base package area
- Added three enhancement packages:
  - `ima-personal`
  - `ima-team`
  - `ima-agent`
- Added nine enhancement sub-skills across personal, team, and agent workflows
- Added package-level and child-skill-level publishing docs:
  - trigger keywords
  - installation notes
  - example prompts
  - selection guidance
- Reworked `README.md` to include:
  - official package link
  - soft dependency explanation
  - full install guidance
  - single add-on install guidance
  - enhancement package overview and examples
- Added `CHANGELOG.md`

### Changed

- Clarified that the root `ima-skill` content remains the official-compatible base layer inside this repository
- Documented that the enhancement suite is aligned to the official `1.2` version boundary for ongoing evolution
